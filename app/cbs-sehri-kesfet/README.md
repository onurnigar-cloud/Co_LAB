# CBS ile Şehri Keşfet

Co_LAB içindeki etkileşimli CBS öğrenme uygulamasıdır.

## Öğrenme akışı

- Basılı gezi rehberi ile dijital haritayı karşılaştırma
- Coğrafi veri katmanlarını açıp kapatma
- Harita üzerindeki mekânları inceleme
- Süre, mesafe ve güzergâh özelliklerine göre rota seçme

Uygulama yolu: `/cbs-sehri-kesfet`
